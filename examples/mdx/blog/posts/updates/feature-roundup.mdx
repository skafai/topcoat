# Release v1.0

We're excited to announce the first stable release of topcoat-mdx!

## What's new

- **`compile_mdx!`** — compile MDX files at build time
- **`mdx_pages!`** — auto-discover and register a directory of MDX files as routes
- **Frontmatter extraction** — parse YAML frontmatter into Rust structs
- **Component embedding** — embed Topcoat components directly in MDX
