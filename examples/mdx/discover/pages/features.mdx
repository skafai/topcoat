# Features

This example demonstrates the following capabilities:

- **Inventory components** — `mdx_components!` registers components that are available across pages
- **Discover router** — `Router::builder().discover().build()` auto-registers `#[page]` functions
- **Auto-page registration** — pages are discovered at link time via inventory

The <Highlight>highlight</Highlight> component used on this page comes from the inventory registration in `main.rs`.
