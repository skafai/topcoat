# Reference Links

Markdown supports reference-style links, which keep your prose clean while defining URLs separately.

Topcoat is a modern web framework built with Rust. You can find it on [GitHub](https://github.com/tokio-rs/topcoat) or learn more about the language itself at [Rust](https://www.rust-lang.org).

Both inline and shorthand link formats are supported by the MDX compiler.
