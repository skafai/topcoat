# Project Roadmap

Here's what we're planning for the coming months:

## Near-term

- More MDX syntax support (footnotes, definition lists)
- Code block meta strings (line highlights, titles)
- Better error messages for macro failures

## Longer-term

- Partial re-rendering of MDX content
- Static site generation (SSG) mode
